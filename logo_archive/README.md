# Logo Archive

A systematic archive of brand identities, featuring carefully documented logos from 1960 to present, with historical context and design analysis.

## Features

- Modern, responsive design
- Component-based architecture
- Animated transitions and interactions
- Comprehensive logo collection
- Historical timeline of brand design
- Curated collections

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/logo-archive.git
cd logo-archive
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:3000`
